# 本地设置 Tab 设计简述

> 状态：R1 已实现
>
> 更新日期：2026-07-30

## 1. 范围

设置页是只读诊断和本机数据维护入口，包含：

- 应用版本、SQLite Schema 版本、固定价格/分红来源、费用和计算口径；
- A 股与境内 ETF 目录最近一次成功快照的实际来源、约定主源、兜底状态、兜底原因和获取时间；
- 每个内置年度交易日历的 `official / pending_official_schedule` 状态和官方来源；
- 导出当前 Schema JSON 备份、从当前版本备份恢复、导出脱敏日志。

恢复流程由 Electron main 选择文件并再次确认。覆盖事务前必须完成当前 Schema 的账本、回测、行情、目录和工作区领域校验，并生成恢复前安全备份；校验失败不得触碰现有数据库。恢复成功后 Renderer 使全部 Query 失效，页面重新读取 SQLite。

## 2. 非目标

- 不在运行期修改费用、行情源、分红源或计算口径；
- 不迁移、不修复、不导入旧数据库或旧版本备份；
- 当前年度日历缺失不阻断应用启动、历史浏览、备份、日志或本页诊断；主界面同时显示高可见告警，相关行情补齐和新回测由服务层阻断；
- 不显示一个混合回测、持仓和目录语义的全局“数据截止日”；
- 不提供数据库文件管理、SQL 控制台、云同步或券商连接。

## 3. 页面状态

- Loading：应用、设置和诊断并行读取时显示内容骨架；
- Error：任一诊断读取失败时显示错误说明，其余可用操作保持可见；
- Empty：尚未形成目录快照时显示“首次加载证券目录后显示实际来源”；
- Pending calendar：未来年度等待官方安排时显示高可见警告，明确“不猜测工作日休市”；
- Action pending：对应按钮独立 loading，避免重复操作；
- Cancelled：文件对话框或恢复确认取消时不显示成功提示、不修改数据；
- Success：导出成功提示完成；恢复成功同时提示安全备份路径并刷新全部查询；
- Failure：IPC、文件、结构校验或恢复失败显示错误信息，现有数据库保持不变。

## 4. 交互与文案

- “导出 JSON 备份”只导出当前 Schema 1；
- “从当前版本备份恢复”使用危险按钮样式，确认框明确会覆盖流水、实验、行情缓存与目录快照；
- 页面固定说明“旧数据库和旧备份不会迁移或补默认值”；
- 日历表展示年度、状态、来源；pending 行显示“尚未发布，不猜测休市日”。

## 5. 验收标准

- [ ] `/settings` 渲染真实页面，不再永久展示 Skeleton；
- [ ] `health`、`getSettings`、`getDiagnostics` 均由页面消费；
- [ ] 可从页面调用 `exportBackup`、`restoreBackup`、`exportLogs`，并区分成功、取消、失败；
- [ ] 恢复成功后所有活跃 Query 重新读取，其他页面不继续展示恢复前缓存；
- [ ] A 股和 ETF 来源分开显示，ETF 兜底时可见实际新浪来源及东方财富失败原因；
- [ ] Schema 版本、固定费用和计算口径可见；
- [ ] 2027 `pending_official_schedule` 显示告警，2024—2026 official 来源可见；
- [ ] 页面明确只接受当前 Schema 1，不暗示支持升级或迁移旧数据。

## 1. 页面结构

```text
页头
  └─ 标题：本地设置
口径面板（workspace-panel）
  ├─ 标题：数据与计算口径 + 健康状态标签
  ├─ Descriptions（2 列）
  │   └─ 本地存储 / 行情截止 / 行情主源 / 分红补充源 / 佣金 / 口径版本
  └─ R1 费用说明（Paragraph）
操作面板（workspace-panel，分三行）
  ├─ 导出 JSON 备份
  ├─ 从 JSON 恢复
  └─ 导出运行日志
页脚免责声明
```

## 2. 口径面板

| 项 | 取值 | 说明 |
| --- | --- | --- |
| 本地存储 | SQLite（sql.js） | 固定 |
| 行情截止 | `health.dataCutoff` | 无快照显示"尚无快照" |
| 行情主源 | 腾讯财经 · 不复权日线 | 固定 |
| 分红补充源 | 东方财富 · 已实施税前现金分红 | 固定 |
| 佣金 | 0 元 | R1 固定简化费用 |
| 口径版本 | `caliberVersion` | 默认 `bank-dca-r1-node-v3` |

健康状态标签：本地服务正常（success）/ 检查中（default）。

R1 费用说明：交易费用固定为 0，不计卖出印花税、分红税、过户费与滑点；期末资产按市值估算，不扣期末卖出费用。

## 3. 操作面板

三行操作，每行包含标题、说明和按钮：

| 操作 | 说明 | 按钮 |
| --- | --- | --- |
| 导出 JSON 备份 | 包含 schema 版本、流水、回测结果与必要设置 | 导出 |
| 从 JSON 恢复 | 校验成功后先生成当前数据的安全备份，再确认覆盖 | 选择文件 |
| 导出运行日志 | 导出启动、回测和数据操作日志；过滤令牌与敏感字段 | 导出日志 |

## 4. 免责声明

页脚显示：仅供研究与记录，不构成投资建议。应用不连接券商、不申请交易权限、不执行下单。

## 5. 数据刷新

- 口径面板：`api.getSettings` + `api.health`
- 恢复成功后：`queryClient.invalidateQueries()` 刷新全部缓存

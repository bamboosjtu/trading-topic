# 持仓明细 UI Brief

> 状态：已审定设计 ｜ 页面入口：`实盘 / 持仓明细` ｜ 效果图：同目录 `持仓明细.png`
>

## 页面目标

单一证券账户的只读分析页，回答：当前持有哪些标的；每个标的的数量、成本、市值、累计投入；浮盈亏、累计分红、总收益；组合与单标的在最近日/周/月/3月/半年/1年的区间表现；估值使用的行情时间。

本页不承担事实写入：所有交易在交易流水页录入，持仓、成本、累计投入与分红均由流水重建，行情刷新只更新估值。R1 单账户：无账户切换、无导入流水、无录入交易按钮；默认只展示当前持有标的。

## 页面结构

```text
标题 + 用途说明              行情更新时间 / 刷新行情 / 导出持仓(唯一主按钮)
工具栏：资产类型 Segmented · 标的搜索 · 排序
账户指标带：总资产/股票市值/累计收益/累计收益率/可用现金/仓位
区间表现面板：组合表现 ⇄ 选中标的表现 × 6 个区间
当前持仓表格（行选中 + 查看详情）
标的详情 Drawer（右侧，只读，520–640px）
底部口径与数据说明
```

## 字段与指标口径

- 总资产 = 股票市值 + 可用现金 + 其他已纳入 R1 的资产；仓位 = 股票市值 / 总资产。
- 累计收益含已实现与未实现；累计收益率、组合与单标的区间表现均由领域层返回，Renderer 不自行计算或拼接行情。
- 组合表现 ≠ 当前累计收益率，二者不共用字段与文案。
- 表格列：标的（名称 + 代码·类型）、持仓数量（股/份）、成本价、现价、市值、累计投入、浮盈亏、累计分红、总收益（至少含浮盈亏 + 分红，最终口径领域层定义）、操作。
- 数据缺失一律显示 `—`，不得以 0.00 冒充真实值。

## 关键交互

- 刷新行情：按钮 Loading 且不清空旧估值；失败保留原数据与更新时间并页内报错。导出与完整持仓事实一致，若导出筛选结果须在按钮或确认文案中明确。
- 搜索支持名称/6 位代码即时过滤（不发请求）；排序默认按总收益降序，控件显示当前字段与方向。
- 单击行选中标的后可切换“选中标的表现”，标题区显示名称与代码；筛选后选中标的不可见时自动回到组合表现并清除选中。
- 查看详情打开 Drawer：持仓事实、区间表现（与页面同一领域结果）、最近 5–10 条流水，`查看全部相关流水`跳转交易流水页并带入标的筛选。
- 分页：≤10 条不显示；默认 10 条/页，可选 10/20/50；表头固定，横向不足时固定标的与操作列。

## 状态与异常

- Loading：首载指标带/区间 Skeleton、表格 Loading；刷新保留旧数据。
- 空：无有效流水显示“尚未形成持仓”+“前往交易流水”按钮，本页不直接打开录入表单。
- 行情过期：保留上次估值，更新时间用警告色，页内提示并提供重新刷新。
- 部分行情缺失：相关标的现价/市值/收益显示 `—`；总资产与组合表现进入 partial 并说明未纳入标的，不输出伪完整汇总。
- 持仓重建失败：阻断指标与表格并可重试；区间失败仅区间面板报错；导出失败用 Message，不破坏页面。

## 验收标准

- 无账户切换、导入流水、录入交易入口；详情只读，可跳转带标的筛选的交易流水。
- 指标带 6 项、区间 6 档完整；支持组合/单标的切换；表格各列完整，数字右对齐、等宽数字。
- 红涨绿跌仅表达收益方向，操作色仍为亮蓝。
- 1920×1080 无页面级横向滚动，核心区域与 ≥10 行表格完整可见；4K 不等比放大字号，扩展留白与行数。
- Loading/空/过期/部分缺失/错误均有明确设计；Renderer 不重算任何领域指标。

# 历史回测 Tab 设计简述

> 所属文档：[PRD_R1.md](../PRD_R1.md) §3.1 / §4
>
> 架构约束：[ARCHITECTURE.md](../ARCHITECTURE.md)
>
> 实现代码：`src/desktop/electron/domain/analysis.ts`、`src/desktop/renderer/src/pages/BacktestPage.tsx`

## 1. 页面结构

历史回测是 R1 唯一完成态页面，其余导航入口使用统一骨架屏。

```text
全局外壳
  ├─ 分组侧栏：研究 / 账户 / 系统
  └─ 顶栏：数据截止日 / 设置 / 本地研究模式
历史回测
  ├─ 参数区：标的 / 区间 / 每月投入 / 费用口径 / 高级设置
  ├─ 六项概览指标
  ├─ 资产、收益率、回撤曲线
  ├─ 标的对比表
  └─ 回测明细 Modal
```

## 2. 参数与概览

| 字段 | 控件 | 约束 |
| --- | --- | --- |
| A 股标的 | `Select mode="multiple" maxCount={4}` | 6 位代码，预设 7 只银行股 |
| 回测区间 | `Input type="date"` | 近 3/5/10 年或自定义 |
| 每月投入 | `InputNumber` | min=100，step=500，默认 3000 |
| 指定买入日 | 高级设置内的 `InputNumber` | 1–28，默认 1 |
| 费用模式 | 只读 `Select` | R1 费用固定为 0 |

概览指标：每标的累计投入、最高最终资产、最高 XIRR、最低最大回撤、
最长亏损时间和最高累计分红。口径说明固定显示不复权收盘价、允许零碎股、
分红回购、剩余资金结转和费用 0 元。

## 3. 曲线与标的对比

- 曲线支持资产、收益率和回撤三种视图，以及全部、1/3/5 年区间；
- 资产视图同时绘制每个标的的累计投入虚线；
- 对比表按最终资产降序，展示累计投入、最终资产、累计收益、累计收益率、
  XIRR、最大回撤、最长亏损时间、累计分红和期末现金；
- 点击“查看详情”打开该标的的回测明细 Modal；
- 盈利用红色、亏损用绿色，与 A 股涨跌习惯一致。

## 4. 回测明细 Modal

- 以 1920×1080 为设计基线，侧栏 256px、顶栏 56px、正文左右留白 32px；
- Modal 固定宽度 990px、高度 730px，距视口顶部约 `22vh`，并相对视口
  中心向右偏移 `3vw`；小屏幕下受
  `100vw/100vh` 安全边距约束；
- 使用无模糊的浅灰蓝半透明遮罩，保留参数区、图表和结果表的上下文层次；
- 目标环境为 1920×1080，默认每页固定 20 条，不显示页大小切换；
- 20 条数据使用紧凑行高，目标是在该分辨率下一屏查看整页，不依赖纵向拖动；
- 表格正文设置独立高度预算，分页器和底部口径始终保留在 Modal 可见区域；
- 表格每次只挂载当前页 20 条，避免内部横向或纵向滚动条；
- 数据来源、更新时间、总条数、固定页大小和分页器统一放在同一底栏；
- 明细按原始时间顺序展示，不提供数值列排序；只有“事件”列保留类型筛选；
- 不提供“实际交易（含费用）”或其他子 Tab；
- 顶部摘要：实际区间、明细条数、累计外部投入、累计分红、当前盈亏率；
- 底部展示回测口径和 provenance。

明细列按以下顺序展示：

| 列 | 说明 |
| --- | --- |
| 日期 | 按原始时间顺序展示，不提供排序 |
| 事件 | 定投买入 / 分红到账 / 分红回购 / 送转入账 |
| 期初现金 | 本事件发生前现金 |
| 外部投入 | 仅定投买入行大于 0 |
| 收盘价 | 当日不复权收盘价 |
| 新增股数 | 买入、分红回购或送转增加的股数 |
| 发生金额 | 成交金额、分红金额或每 10 股送转比例 |
| 累计股数 | 当前累计持股 |
| 累计投入 | 当前累计外部投入，用于 XIRR 与盈亏率分母 |
| 累计分红 | 从回测开始到当前事件的现金分红总额 |
| 期末现金 | 本事件完成后的现金 |
| 盈亏率 | 盈利红、亏损绿、持平中性色 |

同日事件顺序为送转入账 → 分红到账 → 分红回购 → 定投买入。现金分红到账后
立即全额回购原标的；送股/转增不产生现金，只增加股数。

## 5. 计算与展示一致性

- `simulateBacktest` 是 R1 唯一计算事实来源；
- `simulateBacktestSimple` 只把原始交易转换为 Modal 审计行，不重新模拟；
- 每行同时携带累计外部投入、累计分红和盈亏率，禁止用表头替换掩盖字段语义；
- 费用为 0，定投资金与分红资金均可全额买入零碎股；
- 现金分红按登记日持股计算，到账后立即回购；
- 送股/转增按每 10 股比例计算新增股数，在除权日入账。

## 6. 视觉风格

- 白色侧栏与工作区、海军蓝信息层级、亮蓝单一动作色；
- 全局尺寸基线为 256px 侧栏、56px 顶栏、32px 内容边距，侧栏支持收起；
- 依赖留白、细分隔线和排版建立层级，避免装饰性卡片堆叠；
- 数值使用 `tabular-nums`，表格采用金融工作台的紧凑密度；
- 动效只用于页面进入、骨架屏呼吸、图表更新和 Modal 出入场。

## 1. 页面结构

历史回测是 R1 唯一完成态页面，其余导航入口使用统一骨架屏。

```text
全局外壳
  ├─ 分组侧栏：研究 / 实盘 / 系统
  └─ 顶栏：数据截止日
历史回测
  ├─ 二级 Tab：运行回测 / 历史结果
  ├─ 运行回测
  │   ├─ 参数区：标的 / 区间 / 每月投入 / 费用口径 / 高级设置
  │   ├─ 当前实验的六项概览指标
  │   ├─ 当前实验的行情 K 线、收益率曲线、最大回撤曲线
  │   ├─ 当前实验的标的对比表
  │   └─ 回测明细 Modal
  └─ 历史结果
      └─ 不可变实验列表：查看结果 / 复制参数重新回测 / 删除
```

## 2. 参数与概览

| 字段             | 控件                                   | 约束                                             |
| ---------------- | -------------------------------------- | ------------------------------------------------ |
| A 股标的         | `Select mode="multiple" maxCount={10}` | 产品域获取并缓存全 A 股代码表，支持名称/代码检索 |
| 回测区间         | 快捷按钮                               | 3/5/10/15 年；精确日期移入高级设置               |
| 每月投入         | `InputNumber`                          | min=100，step=500，默认 3000                     |
| 指定日期与买入日 | 高级设置内的日期输入和 `InputNumber`   | 开始/结束日期；买入日 1–28，默认 1               |
| 费用模式         | 只读文本                               | R1 费用固定为 0                                  |

概览指标：累计投入、最高最终资产、最高 XIRR、最高累计分红、最大回撤和
最长连续回撤（含起止月份）。详细口径由标题旁“回测规则说明”展开，避免参数区
出现第二条重复工具栏。

## 3. 曲线与标的对比

- 图表固定提供“行情 K 线 / 收益率曲线 / 最大回撤曲线”三个 Tab；
- 行情 K 线提供当前结果标的切换，支持日 K、周 K、月 K，默认日 K；均线固定为 MA5、MA10、MA20、MA60。数据为产品域独立获取的前复权真实日 OHLCV，不读取 Labs 或 Research，也不从回测不复权收盘价伪造；
- 日 K 直接展示；周/月 K 使用首日开盘、周期最高/最低、末日收盘和成交量合计。K 线只用于快速了解走势，不作为严格回测证据；
- K 线明确区分加载中、可用、不可用和错误状态；收益率与回撤序列由领域层计算，Renderer 只格式化和绘图；
- 收益率与最大回撤视图用于多标的同条件对比；
- 对比表只读取当前 `activeExperimentId` 对应实验，不读取全部历史结果；
- 当前实验内所有标的具有同一区间、每月投入、买入规则、数据截止和口径版本；
- 对比表按 XIRR 降序，展示累计投入、最终资产、XIRR、累计分红、最大回撤、最长亏损时间和期末现金；
- 对比表的表头为 13px，主数据与“查看详情”统一为 14px；次级参数说明为 11px；
- 当前实验导出为 XLSX：首个 sheet 是汇总，之后每个标的一个审计明细 sheet；
- 点击“查看详情”打开该标的的回测明细 Modal；
- 盈利用红色、亏损用绿色，与 A 股涨跌习惯一致。

## 4. 历史结果

- 一行代表一次点击“开始回测”生成的不可变实验，而不是单个标的结果；
- 列固定为运行时间、回测区间、每月投入、标的数量、最佳 XIRR、最大回撤、数据截止和操作；
- “查看结果”把实验加载到“运行回测”并进入只读状态；
- “复制参数重新回测”只复制请求，不复制结果，也不创建策略对象；
- “删除”删除实验和全部标的结果；若它是当前实验，同时清除工作区引用；
- 相同请求重新运行仍产生新实验，不覆盖历史记录。

## 5. 回测明细 Modal

- 以 1920×1080 为设计基线，侧栏 256px、顶栏 56px、正文左右留白 32px；
- Modal 固定宽度 1280px、高度 820px；在 Electron 标题栏存在时把网页内顶部偏移设为 38px，使 1920×1080 实际屏幕的视觉顶边约为 68px；
- 使用无模糊的中性深色半透明遮罩，保留背景结构但不与明细争夺注意力；
- 目标环境为 1920×1080，默认每页固定 20 条，不显示页大小切换；
- 表格正文与表头使用 12px 字号；20 条数据采用 28px 行高，目标是在该分辨率下一屏查看整页，不依赖纵向拖动；
- 表格正文设置独立高度预算，分页器和底部口径始终保留在 Modal 可见区域；
- 表格每次只挂载当前页 20 条，避免内部横向或纵向滚动条；
- 数据来源、更新时间、总条数、固定页大小和分页器统一放在同一底栏；
- 明细按原始时间顺序展示，不提供数值列排序；只有“事件”列保留类型筛选；
- 不提供“实际交易（含费用）”或其他子 Tab；
- 顶部摘要：实际区间、明细条数、累计外部投入、累计分红、当前盈亏率；
- 底部展示回测口径和 provenance。

明细列按以下顺序展示：

| 列       | 说明                                      |
| -------- | ----------------------------------------- |
| 日期     | 按原始时间顺序展示，不提供排序            |
| 事件     | 定投买入 / 分红到账 / 分红回购 / 送转入账 |
| 期初现金 | 本事件发生前现金                          |
| 外部投入 | 仅定投买入行大于 0                        |
| 收盘价   | 当日不复权收盘价                          |
| 新增股数 | 买入、分红回购或送转增加的股数            |
| 发生金额 | 成交金额、分红金额或每 10 股送转比例      |
| 累计股数 | 当前累计持股                              |
| 累计投入 | 当前累计外部投入，用于 XIRR 与盈亏率分母  |
| 累计分红 | 从回测开始到当前事件的现金分红总额        |
| 期末现金 | 本事件完成后的现金                        |
| 盈亏率   | 盈利红、亏损绿、持平中性色                |

同日事件顺序为送转入账 → 分红到账 → 分红回购 → 定投买入。现金分红到账后立即全额回购原标的；送股/转增不产生现金，只增加股数。

## 6. 计算与展示一致性

- `simulateBacktest` 是 R1 唯一计算事实来源；
- `backtestResultToSimpleResult` 只把已持久化的主结果转换为 Modal 和 XLSX 审计行，不重新请求行情或重新模拟；
- 每行同时携带累计外部投入、累计分红和盈亏率，禁止用表头替换掩盖字段语义；
- 费用为 0，定投资金与分红资金均可全额买入零碎股；
- 现金分红按登记日持股计算，到账后立即回购；
- 送股/转增按每 10 股比例计算新增股数，在除权日入账。

## 7. 视觉风格

- 白色侧栏与工作区、海军蓝信息层级、亮蓝单一动作色；
- 全局最小窗口宽度为 1920px；尺寸基线为 256px 固定侧栏、56px 顶栏；
- 依赖留白、细分隔线和排版建立层级，避免装饰性卡片堆叠；
- 数值使用 `tabular-nums`，表格采用金融工作台的紧凑密度；
- 动效只用于页面进入、骨架屏呼吸、图表更新和 Modal 出入场。

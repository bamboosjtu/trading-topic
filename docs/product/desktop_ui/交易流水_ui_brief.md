>

## 页面目标

R1 实盘唯一事实写入页：手工录入买入、卖出、分红、资金转入/转出、国债逆回购；查询核对历史；以追加式修正/冲正纠错；为持仓明细、账户资产与收益日历提供统一事实源。

数据流：交易流水（唯一事实源）→ 重建持仓/成本/现金/累计分红 → 持仓明细与收益日历只读展示。

R1 边界：单账户无切换；不支持导入券商流水；业务时间只精确到日期（YYYY-MM-DD）；不要求流水号、订单号、对手方或精确录入时间；内部 ID 不上界面；原记录不物理删除；持仓与收益不在本页由 Renderer 重算。

## 页面结构

```text
标题 + 用途说明              数据截止日期 / 录入交易（唯一主按钮）
筛选区：日期范围 · 交易类型 · 标的类型 · 标的 · 备注 · 重置 · 查询
统计指标带：记录总数/累计买入/累计卖出/累计分红/资金净流入
交易记录表格 ＋ 交易详情 Drawer（右开 380–460px，表格自适应缩窄）
录入交易 Modal（居中）
底部：手动录入事实源固定提示
```

## 字段与指标口径

- 指标带默认统计当前筛选结果：记录总数；累计买入（含费用，表实际资金流出）；累计卖出（含费用，取领域层定义的卖出净流入）；累计分红（分红到账合计）；资金净流入 = 外部转入 − 外部转出（不把证券买卖、分红重复计入）。所有汇总由领域层或查询服务返回。
- 表格列：日期、标的（无标的 `—`）、交易类型（低饱和 Tag，仅分类不表涨跌）、数量/份额、价格、金额、手续费、备注（超长省略 + Tooltip）、查看。
- 默认排序：业务日期降序，同日按内部创建顺序稳定排序，排序键不外显。

## 关键交互

- 录入交易 Modal：交易类型与业务日期必填，按类型动态出字段——买卖：标的/数量/价格/手续费；分红：标的/金额；资金转入转出：金额；逆回购：本金/到期日期/到期金额。买卖金额由数量×价格自动计算只读；提交前显示“本次操作影响摘要”（现金、持仓、成本、累计分红、待到期资产变化），摘要取领域层预校验结果，Renderer 不推导第二套口径。
- 校验由领域层完成（金额有限非负、数量价格精度、卖出 ≤ 可卖持仓、日期边界、到期日不早于业务日），前端仅即时提示。
- 修正/冲正不在普通录入中提供，必须从原记录详情发起：编辑 = 追加修正记录，原记录可追溯并显示修正关系；冲正需二次确认，生成反向影响记录，不物理删除，已完整冲正不得重复冲正。
- 详情 Drawer 展示通用字段 + 类型扩展字段（资金金额、逆回购本金/到期、分红金额、关联原记录），不展示流水号、内部 ID、固定来源与精确录入时间。
- 分页默认 20 条/页，可选 20/50/100；表头固定；行内不提供直接编辑或删除。

## 状态与异常

- Loading：首载指标带 Skeleton、表格 Loading；查询切换保留筛选、局部 Loading；保存/修正/冲正期间禁止重复提交。
- 空：无任何流水显示“尚未录入交易流水”+“录入第一笔交易”；筛选为空显示“当前条件下没有匹配记录”+“重置筛选”。
- 保存失败：Modal 保留已填内容与错误原因，不关闭，不产生半条记录。
- 重建失败（流水已存但持仓重建失败）：属严重一致性错误，页面持续 Alert，禁止展示伪完整持仓或收益，引导重试，事实记录不得静默丢失。

## 验收标准

- 无账户切换、导入流水、流水号字段；时间只到日期；“录入交易”为唯一写入入口。
- 修正/冲正只能从原记录发起；编辑追加不覆盖；冲正不物理删除，关联关系可识别。
- 指标带 5 项与表格列完整；详情不展示内部字段；汇总与影响摘要均由领域层返回。
- 1920×1080 下筛选、指标带与 ≥10 行记录首屏完整可见；4K 保持字号尺度、扩展列宽与行数。
- Loading/空/查询无结果/保存失败/重建失败均有明确状态。

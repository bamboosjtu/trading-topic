## 1. 页面结构

```text
页头
  ├─ 标题：交易流水
  └─ 新增流水按钮
流水表（Table，分页 12 条/页）
  └─ 列：业务日期 / 类型 / 股票·品种 / 金额 / 数量 / 备注 / 冲正操作
新增流水 Modal
  └─ 按类型动态展示字段
```

## 2. 流水表

| 列 | 宽 | 说明 |
| --- | --- | --- |
| 业务日期 | 120 | `businessDate` |
| 类型 | 125 | Tag 展示中文标签 |
| 股票 / 品种 | — | `symbol` 或 `repoCode`，无则"—" |
| 金额 | — | `amount` 或 `price × quantity` |
| 数量 | — | `quantity`，无则"—" |
| 备注 | — | `note`，超长省略 |
| 操作 | 86 | 冲正按钮 / 已冲正标签 |

**类型标签**：

| 值 | 中文 |
| --- | --- |
| `transfer_in` | 资金转入 |
| `buy` | 买入 |
| `sell` | 卖出 |
| `dividend` | 现金分红 |
| `reverse_repo` | 国债逆回购 |
| `transfer_out` | 资金转出 |
| `adjustment` | 冲正 / 修正 |

**分页**：每页 12 条。

**冲正**：点击"冲正"按钮弹出确认框，确认后创建反向记录，原记录保持不变。`adjustment` 类型行显示"已冲正"，不可再次冲正。

## 3. 新增流水 Modal

按类型动态展示字段：

| 类型 | 必填字段 |
| --- | --- |
| 资金转入 | 金额 |
| 资金转出 | 金额 |
| 买入 | 股票代码、成交价、数量、费用 |
| 卖出 | 股票代码、成交价、数量、费用 |
| 现金分红 | 金额、股票代码、登记日、到账日 |
| 国债逆回购 | 本金、品种、年化收益率、期限、到期日、到期金额 |

所有类型共有：业务日期（默认今天）、备注。

**约束**：
- 买入/卖出数量必须是 100 股整数倍
- 股票代码必须是 6 位 A 股代码
- 金额、价格必须大于 0

## 4. 数据刷新

- 进入页面时通过 `api.listLedger` 拉取
- 新增/冲正后同时刷新流水和账户（`invalidateQueries` for `["ledger"]` and `["account"]`）

## 5. 口径

- 追加式记录，已保存流水不可原地覆盖
- 冲正通过新增关联记录使原记录失效
- 修正由"冲正原记录 + 新增正确记录"组成
- 账户余额始终由有效流水重算

## 页面目标

R1 实盘事实核对页：查询买入、卖出、分红、资金转入/转出、国债逆回购与冲正/修正记录；为持仓明细、账户资产与收益日历提供可追溯的统一事实源。

数据流：交易流水（唯一事实源）→ 重建持仓/成本/现金/累计分红 → 持仓明细与收益日历只读展示。

R1 当前界面边界：单账户无切换；不提供录入交易、导入券商流水、编辑、删除或冲正入口；业务时间只精确到日期（YYYY-MM-DD）；不要求流水号、订单号、对手方或精确录入时间；内部 ID 不上界面；原记录不物理删除；持仓与收益不在本页由 Renderer 重算。底层账本契约保留追加式记录能力，但不属于本轮页面职责。

## 页面结构

```text
标题 + 用途说明                                      导出流水
筛选区：日期范围 · 交易类型 · 标的类型 · 标的 · 备注
统计指标带：记录总数/累计买入/累计卖出/累计分红/资金净流入
交易记录表格 ＋ 交易详情 Drawer（右开 380–460px，表格自适应缩窄）
底部：本地事实源与冲正可追溯提示
```

## 字段与指标口径

- 指标带默认统计当前筛选结果：记录总数；累计买入（含费用，表实际资金流出）；累计卖出（含费用，取领域层定义的卖出净流入）；累计分红（分红到账合计）；资金净流入 = 外部转入 − 外部转出（不把证券买卖、分红重复计入）。所有汇总由领域层或查询服务返回。
- 表格列：日期、标的（无标的 `—`）、交易类型（低饱和 Tag，仅分类不表涨跌）、数量/份额、价格、金额、手续费、备注（超长省略 + Tooltip）、查看。
- 默认排序：业务日期降序，同日按内部创建顺序稳定排序，排序键不外显。

## 关键交互

- 筛选条件直接提交给查询服务；记录数、买卖金额、分红与资金净流入均由服务返回，Renderer 不遍历当前页临时汇总。
- 冲正记录与被冲正原记录均保留，并在类型 Tag 和详情中明确状态；本页不提供发起冲正或修改事实的动作。
- 详情 Drawer 只读展示通用字段 + 类型扩展字段（资金金额、逆回购本金/到期、分红金额、关联状态），不展示流水号、内部 ID、固定来源与精确录入时间。
- 导出沿用当前筛选条件，在主进程生成 XLSX；Renderer 不读取文件系统。
- 分页默认 20 条/页，可选 20/50/100；表头固定；行内不提供直接编辑或删除。

## 状态与异常

- Loading：首载指标带 Skeleton、表格 Loading；查询切换保留筛选、局部 Loading。
- 空：无任何流水显示“暂无交易流水”，并明确本页不提供录入或导入；筛选为空显示“当前条件下没有匹配记录”。
- 查询或导出失败：保留筛选条件，展示错误原因并允许重试。
- 重建失败（流水已存但持仓重建失败）：属严重一致性错误，页面持续 Alert，禁止展示伪完整持仓或收益，引导重试，事实记录不得静默丢失。

## 验收标准

- 无账户切换、录入交易、导入流水、修改、删除、冲正动作或流水号字段；时间只到日期。
- 冲正不物理删除，原记录和关联状态可识别。
- 指标带 5 项与表格列完整；详情不展示内部字段；筛选汇总由领域层返回。
- 1920×1080 下筛选、指标带与 ≥10 行记录首屏完整可见；4K 保持字号尺度、扩展列宽与行数。
- Loading/空/查询无结果/部分数据/查询失败/重建失败均有明确状态。

# 交易流水 UI Brief

>

## 页面目标

R1 实际投资唯一事实写入页：手工录入买入、卖出和现金分红；查询核对历史；
以追加式修正/冲正纠错；为持仓明细与收益日历提供统一事实源。

数据流：交易流水（唯一事实源）→ 重建持仓、成本、买卖现金流与累计分红 → 持仓明细与收益日历只读展示。

R1 边界：单账户无切换；不支持导入券商流水；业务时间只精确到日期（YYYY-MM-DD）；不要求流水号、订单号、对手方或精确录入时间；内部 ID 不上界面；原记录不物理删除；持仓与收益不在本页由 Renderer 重算。

## 页面结构

```text
标题 + 用途说明                         数据截止日期 / 录入交易（唯一主按钮）
筛选区：日期范围 · 交易类型 · 标的类型 · 标的 · 备注 · 重置 · 查询
统计指标带：记录总数/累计买入支出/累计卖出净收入/累计分红/累计净投入
交易记录表格 ＋ 交易详情 Drawer（右开 380–460px，表格自适应缩窄）
录入交易 Modal
底部：手动录入事实源提示
```

## 字段与指标口径

- 指标带默认统计当前筛选结果：记录总数；累计买入支出（成交金额 + 费用）；累计卖出净收入（成交金额 − 费用）；累计分红（到账金额合计）；累计净投入（买入支出 − 卖出净收入 − 分红）。所有汇总由领域层或查询服务返回。
- 表格列：日期、标的（无标的 `—`）、交易类型（低饱和 Tag，仅分类不表涨跌）、数量/份额、价格、金额、手续费、备注（超长省略 + Tooltip）、查看。
- 默认排序：业务日期降序，同日按内部创建顺序稳定排序，排序键不外显。

## 关键交互

- 录入 Modal 按类型动态显示字段：
  - 买入/卖出：标的、实际数量/份额、价格、手续费；股票买入提示 100 股整数倍但不阻断，卖出允许零股清仓；
  - 现金分红：标的、分红到账日（即业务日期）、到账金额，可选每股分红/登记日；不再提供另一套可与业务日期不一致的到账日；
- 快捷操作“分红并再投入”收集分红日期/金额和再投入日期/价格/数量/手续费，再投入日期不得早于到账日；先展示两条事实的合并影响预览，再在同一事务中写入两条共享内部关联编号、可独立审计的事实。
- 成交金额只读自动计算；提交前显示“本次影响摘要”：标的数量、持仓成本、累计买入支出、累计卖出净收入、累计分红与累计净投入变化。摘要由领域层预校验返回，Renderer 不重复实现账本公式。
- 校验由领域层负责：金额/价格/数量有限且非负、精度合法；数量按实际整数股/份记录；卖出数量不得超过截止业务日的有效持仓；分红到账日不早于登记日；业务日期不得晚于 A 股市场当前自然日。买卖的已确认休市日直接拒绝；本地交易日覆盖不足时给出核对成交凭证警告；分红可在非交易日到账。失败时 Modal 保持打开、保留输入并聚焦错误字段。
- 修正/冲正只能从原记录详情发起：
  - “追加修正”预填原记录，提交后新增修正记录，不覆盖原记录；
  - “冲正”二次确认后新增反向影响记录，不物理删除；
  - 已冲正原记录与关联修正/冲正记录需明确状态，禁止重复冲正。
- 详情 Drawer 展示通用字段、审计时间和组合录入关联状态；显示“关联操作：分红并再投入”以及可点击的关联买入/分红事实，不展示内部 UUID。
- 分页默认 20 条/页，可选 20/50/100；表头固定；行内不提供直接编辑或删除。

## 状态与异常

- Loading：首载指标带 Skeleton、表格 Loading；查询切换保留筛选、局部 Loading；保存按钮显示进度并阻止重复提交。
- 空：无任何流水显示“暂无交易流水” + “录入第一笔交易”；筛选为空显示“当前条件下没有匹配记录”。
- 保存失败：保留 Modal 与用户输入，显示可操作错误；不插入半条记录。
- 重建失败（流水已存但持仓重建失败）：属严重一致性错误，页面持续 Alert，禁止展示伪完整持仓或收益，引导修正事实记录；原始流水不得静默丢失。

## 验收标准

- 无账户切换、券商导入、流水号和精确到时分秒的业务时间；“录入交易”是唯一事实写入口。
- 修正/冲正只从原记录发起，采用追加记录且不覆盖/删除原记录；重复冲正被阻止。
- 普通录入只包含买入、卖出和现金分红；分红并再投入要么两条事实都成功，要么都不落库。
- 指标带 5 项、表格列、详情字段与“本次影响摘要”均由领域口径支撑，不在 Renderer 重建投资收益。
- 1920×1080 下筛选、指标带与 ≥10 行记录首屏完整可见；4K 保持字号尺度、扩展列宽与行数。
- Loading/空/筛选无结果/保存失败/部分数据/重建失败均有明确状态。

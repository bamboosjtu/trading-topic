## 页面目标

按月份汇总实际持仓相关的股权登记日、除权除息日和到账日，帮助用户核对现金分红。页面只展示和记录，不连接券商、不预测或执行交易。

## 后续验收

- 日期、股票代码、事件类型和来源可追溯；
- 已到账金额来自有效流水，预计事项与已确认事项视觉区分；
- 缺失到账日时明确显示“待确认”，不得推造日期；
- 使用冷白、墨蓝、亮蓝设计系统，金额使用等宽数字。

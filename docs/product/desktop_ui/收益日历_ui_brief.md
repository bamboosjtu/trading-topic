## 页面目标

解释股票与 ETF 投资每天收益为什么变化：当日总收益来自市场价格、分红还是
交易影响，贡献最大的持仓，以及本月/年初至今/累计收益和当日投资事件。
月历主视图 + 右侧选中日期详情，只读，不录入、不修改持仓与分红。

数据流：交易流水 + 实盘专用每日行情缓存 → 日度持仓快照与收益归因（领域层统一计算）→ 本页。R1 按收盘价计日度市场价格收益，不提供盘中实时收益；非交易日无事件默认无收益。

## 页面结构

```text
标题 + 用途说明        上一月/月份选择/下一月 · 标的筛选 · 导出日历(次级)
收益指标带：本月收益/市场价格收益/分红收益/累计收益/年初至今（主金额+副收益率）
月历主视图(约65–70%)   选中日期详情(约30–35%，常驻不用 Drawer)
                       ├─ 当日收益摘要：价变/分红/收益率 + 占比
                       ├─ 收益明细表（按贡献）
                       └─ 当日事件
底部：图例 + 数据截止时间与口径说明
```

## 字段与指标口径

- 市场价格收益只由期初持仓数量与相邻有效收盘估值价变化产生；分红收益 = 月内分红到账合计（按到账业务日计入，再投资不重复计为新收益）；交易影响包含成交价与当日正式收盘估值价之差及手续费（不利影响为负）。
- 当日总收益 = 市场价格收益 + 分红收益 + 交易影响。累计收益自首笔有效投资事实起；年初至今为所在自然年至数据截止日。
- 所有日/月/累计收益与收益率由领域层返回；Renderer 不临时重算正式口径。
- 日期格：日期数字、当日总收益（主值）、价变/分红拆分，并在发生时追加交易影响；分红事件使用蓝色标记；格内不显示百分比；空间不足时优先保留总收益。
- 明细表列：标的、持仓变动、市场价格收益、分红收益、交易影响、收益合计，末行合计；无收益显示 0.00，仅该日实际持有标的缺行情时显示 `—`。
- 业务日期只精确到日；数据截止时间可精确到分钟。

## 关键交互

- 月份切换支持上月/下月与 MonthPicker，默认打开数据截止月，切换保留标的筛选。
- 标的筛选：全部/当前持仓/当月曾持有标的；选单标的后日历、指标带、明细全部切换为“单标的贡献”口径并明确标注，不得误称账户总收益。
- 单击日期更新右侧详情；默认选中数据截止日，无数据则选当月最近有收益或事件的日期；支持键盘方向键移动。
- 导出当前月份与当前筛选：日期、总收益、价变收益、分红收益、收益率、标的贡献明细、当日事件。
- 当日事件含分红（标的/数量/每股派息/金额）、买卖以及修正/冲正后的当前有效事实；`查看当日相关流水`跳转交易流水页并带入日期与标的筛选。

## 状态与异常

- Loading：首载指标带与详情 Skeleton、日历 Loading；切换月份/标的保留布局局部更新，不闪白。
- 月份无数据：显示“本月暂无收益记录”+说明，可提供返回最近有记录月份，不渲染全零日历。
- 当日无收益：显示 ¥0.00 + 说明；有交易事件仍展示事件列表。
- 部分行情缺失：日期格显示 `—` 不显示 0；月度指标进入 partial 并列出缺失日期或标的；已确认分红仍可显示，但总收益不冒充完整结果。
- 计算失败：日历级持续 Alert + 重试；单日详情失败仅右侧报错、保留其余；导出失败用 Message。
- 当前月份行情过期：保留上次结果，截止时间警告色并提示“收益按上次成功行情计算”。已结束历史月份只判断所需区间是否完整，不因距今天较久标记过期。

## 验收标准

- 页面名称为“收益日历”；同时展示价格变化与分红收益；指标带 5 项完整。
- 月历周一至周日；日期格显示总收益与价/分拆分；正红负绿并带 +/- 符号，分红事件用蓝色标记。
- 单击日期后右侧展示摘要、贡献明细与事件；全部/单标的筛选口径标注明确。
- 事件可跳转带筛选条件的交易流水页；页面无任何录入或修改入口。
- 收益与收益率全部由领域层返回；1920×1080 下指标带 + 完整月历 + 右侧详情同屏可见；4K 保持尺度、扩展宽度；各异常状态均有明确设计。

# Lab 03：板块周期轮动研究大纲

## 一、研究目标

研究 2010 年以来 A 股主要行业板块的价格周期与领先地位更替，回答三个递进问题：

1. 板块收益是否存在足够大的横截面差异，形成“轮动空间”？
2. 当期领先或落后的板块，在后续月份是否表现出可重复的持续或反转规律？
3. 使用当时可得数据构造的简单轮动规则，在计入换手成本后是否稳定优于等权行业组合和沪深300？

本 Lab 研究的是**行业价格周期**，不把 PMI、PPI 等宏观数据的事后标签混入主分析。
经济周期与行业基本面的因果解释留待后续研究。

## 二、板块口径选择

### 主研究：沪深300十大行业指数

采用中证行业分类下的沪深300十大行业指数：

| 代码 | 板块 |
| --- | --- |
| 000908 | 能源 |
| 000909 | 原材料 |
| 000910 | 工业 |
| 000911 | 可选消费 |
| 000912 | 主要消费 |
| 000913 | 医药卫生 |
| 000914 | 金融地产 |
| 000915 | 信息技术 |
| 000916 | 通信服务 |
| 000917 | 公用事业 |

选择理由：

- 十个指数均有连续覆盖 2010 年以来的历史；
- 使用同一个沪深300母指数，行业之间的样本空间和编制体系可比；
- 行业数足以研究轮动，又避免过细行业带来的历史缺失和多重检验问题。

### 不作为主研究：当前31个申万一级行业

接口体检发现，当前31个申万一级行业中有11个序列只从2014年开始，石油石化、环保、
美容护理只从2021年开始。若强行从2010年拼接，会混用分类版本或虚构历史。因此本 Lab
不把当前申万31行业用于全期轮动检验；它们只适合作为2014年或2021年后的细分扩展。

## 三、时间和价格口径

- 日行情抓取截止：2026-07-29，排除 2026-07-30 盘中数据；
- 月度研究区间：2010-01 至 2026-06，只使用完整月份；
- 价格：行业价格指数和沪深300价格指数，不含现金分红再投资；
- 月收益：月末收盘价相对上月末收盘价的简单收益率；
- 轮动信号：仅使用月末已经形成的数据，持有下一完整月份，禁止同月收益选股。

## 四、数据来源与质量检查

### 主源

- 腾讯财经指数日线，经 AKShare `stock_zh_index_daily_tx` 获取；
- 覆盖十大行业指数和沪深300；
- 同一轮研究固定供应商和版本，不与其他复权或指数口径混用。

### 校验源

- 新浪财经指数日线，经 AKShare `stock_zh_index_daily` 获取；
- 在双方共同日期比较收盘价相对差异；
- 新浪部分行业序列较早停止更新，只用于重叠历史区间校验，不用于补齐主序列。

### 质量门禁

- 十个行业和沪深300都必须覆盖 2010-01 至 2026-07-29；
- `series + date` 主键不得重复，收盘价不得为空或非正；
- 每个完整月份必须恰好形成一个月末观察；
- 腾讯与新浪共同日期的最大收盘价相对差异不得超过 0.1%；
- 2010-01 至 2026-06 的十行业月收益不得缺失；
- 所有策略信号必须至少滞后一个月进入收益计算。

## 五、分析模块

### 模块1：轮动空间

- 年度和 2026 上半年行业收益热力图；
- 每年冠军、前三名和末位行业；
- 月度行业收益横截面标准差；
- 月度最佳与最差行业收益差；
- 不同板块成为月度冠军的次数和最长连胜。

### 模块2：领先地位更替

- 月度冠军变化率；
- 前三行业相邻月份 Jaccard 相似度；
- 前三行业每月新进入数量；
- 领先行业连续停留月数。

这些指标回答“板块有没有轮动”，但不直接回答“轮动能否预测”。

### 模块3：跨期持续性

- 当月行业收益排名与下月排名的 Spearman Rank IC；
- 3、6、12个月累计收益排名与下月收益排名的 Rank IC；
- 前三行业下月收益相对其余行业的收益差；
- 正 Rank IC 比例和 t 统计量。

### 模块4：无前视轮动规则

预先测试六个规则：

- 3个月动量 × Top 3 / Top 5；
- 6个月动量 × Top 3 / Top 5；
- 12个月动量 × Top 3 / Top 5。

每月末按过去累计收益排序，等权持有下一月排名最高的板块。比较：

- 等权十大行业；
- 沪深300；
- 毛收益；
- 单边换手成本 10、20、50 bp 后收益。

统一评估区间从 2011-01 开始，使不同回看期可在相同月份比较。

### 模块5：稳健性

- 2011-2014、2015-2019、2020-2026H1 三个子区间；
- CAGR、年化波动、最大回撤、Sharpe、月胜率和年化换手；
- 参数矩阵是否方向一致，而不是只选择事后最优组合；
- 参考规则固定为“12个月动量 Top 3、单边成本20 bp”。

## 六、图表与输出

Notebook 至少生成：

1. 年度行业收益热力图；
2. 月度冠军板块时间带；
3. 横截面离散度与最佳—最差价差；
4. 动量 Rank IC 对比；
5. 参考轮动规则、等权行业和沪深300累计净值；
6. 参数及交易成本敏感性表；
7. 子区间稳健性表。

可再生数据、CSV、Parquet、PNG 和运行清单写入本 Lab 的 `data/`，默认不提交 Git。

## 七、结论判定标准

只有同时满足以下条件，才可称为“具有可利用的轮动证据”：

1. 多个回看期的平均 Rank IC 为正，而不是单一参数偶然为正；
2. 扣除预设20 bp单边成本后，参考策略长期收益优于等权行业或沪深300；
3. 优势不完全由单一子区间贡献；
4. 最大回撤和换手没有显著恶化到不可实施；
5. 结果不依赖未来数据、当月收益或不完整月份。

否则，只能得出“存在板块涨跌差异和领先更替”，不能得出“可稳定预测或可交易”。

本实验不构成投资建议。

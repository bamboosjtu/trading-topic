# Lab 03：板块周期轮动研究

## 实验目标

研究2010年以来沪深300十大行业的价格周期、领先地位更替、跨期持续性和简单轮动规则，
并区分“存在轮动现象”与“存在可交易预测力”。

## 文件

| 文件 | 职责 |
| --- | --- |
| `0-研究大纲.md` | 研究问题、板块选择、口径、分析模块和结论判定标准 |
| `1-板块周期轮动研究.ipynb` | 数据获取、双源校验、轮动统计、Rank IC、无前视策略和成本敏感性 |
| `2-总体研究结论.md` | 汇总实证结果、适用边界、失败路径和下一步研究 |
| `build_notebook.py` | 以可审阅的 Python 源生成 Notebook |

可再生数据、表格、图表和运行清单写入本目录的 `data/`，默认不提交 Git。

## 研究口径

- 行业：中证行业分类下的沪深300十大行业指数；
- 日数据截止：2026-07-29；
- 月度研究：2010-01至2026-06，共198个完整月份；
- 策略比较：2011-01至2026-06，共186个月；
- 主源：腾讯财经指数日线；
- 校验源：新浪财经指数日线；
- 收益：价格指数收益，不含股息再投资；
- 参考规则：12个月动量Top 3，月末形成信号、下一月持有，单边成本20 bp。

当前31个申万一级行业没有完整的2010年以来同口径历史，因此不用于本 Lab 主分析。

## 运行

从仓库根目录执行：

```powershell
uv sync --project labs
uv run --project labs jupyter nbconvert --to notebook --execute --inplace `
  "labs\03_板块周期轮动研究\1-板块周期轮动研究.ipynb" `
  --ExecutePreprocessor.timeout=1200
```

首次运行需要获取22条指数序列，之后默认复用 `data/` 缓存。删除缓存或把 Notebook 参数
`REFRESH_DATA` 改为 `True` 可强制刷新。

本实验不构成投资建议。

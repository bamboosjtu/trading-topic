# Lab 2：银行股标准数据集

## 目标

将各数据接口返回值整理为统一的研究数据集，使回测、图表和校验代码不再直接调用接口，而是读取标准表。目标是让数据获取与数据使用彻底解耦：

- 接口变化时只需重跑数据获取脚本，回测代码无需修改；
- 原始返回值与清洗后数据并存，便于事后复核；
- 研究包（`research/bank-dca/`）与产品后端（`src/`）共享同一份标准表定义。

本 Lab 是 Lab 3～Lab 5 的数据基础。Lab 1 的 Notebook 仍保留独立的逐股数据获取与质量检查，本 Lab 在其之上抽取稳定的标准化层。

## 标准表清单

至少形成以下 8 张标准表，统一存放在 `labs/data/lab2/`：

### 1. 证券基本信息 `security_info.csv`

| 字段 | 类型 | 说明 |
|---|---|---|
| `symbol` | str | 6 位证券代码，前补零 |
| `name` | str | 证券简称 |
| `exchange` | str | SSE / SZSE / BSE |
| `list_date` | date | 上市日期 |
| `exchange_industry` | str | 交易所行业分类 |
| `security_type` | str | 固定 `A-share` |
| `f10_is_bank` | bool | mootdx F10 主营文本是否确认为银行 |
| `f10_matches` | str | 命中的银行关键词，`|` 分隔 |
| `manual_verified` | bool | 是否在人工核验清单中 |
| `manual_review_as_of` | date | 人工核验清单截止日 |

来源：`labs/01_银行股定投回测/bank_dca.py#fetch_exchange_stock_lists` + `fetch_f10_classification` + `finalize_bank_universe`。

### 2. 交易日历 `trading_calendar.csv`

| 字段 | 类型 | 说明 |
|---|---|---|
| `date` | date | 交易日 |
| `exchange` | str | SSE / SZSE / BSE |
| `is_open` | bool | 当日是否开市 |

用于 `contribution_dates` 的非交易日顺延判断。Lab 1 当前从行情序列隐式推导交易日；本 Lab 显式落盘，避免行情缺数据时顺延逻辑出错。

### 3. 每日不复权行情 `prices/daily_raw_<symbol>.parquet`

| 字段 | 类型 | 说明 |
|---|---|---|
| `date` | date | 交易日 |
| `symbol` | str | 6 位代码 |
| `open` | float | 开盘价 |
| `high` | float | 最高价 |
| `low` | float | 最低价 |
| `close` | float | 收盘价（不复权） |

每只股票一个文件。前复权行情另存为 `prices/daily_qfq_<symbol>.parquet`，字段相同，`adjustment` 为 `qfq`，仅用于连续走势展示，不进入现金流回测。

来源：`labs/01_银行股定投回测/bank_dca.py#fetch_price_bundle`（腾讯主源 + 新浪备源 + 双源差异校验）。

## 质量门禁

每张标准表落盘前必须通过以下检查，不合格的记录保留但标记，不静默丢弃：

### 行情表

- 日期升序、无重复、无空收盘价；
- OHLC 全部为正数，`low ≤ high`；
- 成交量非负；
- 最大日历间隔超过 20 天时标记警告（停牌或数据缺失）；
- 双源共同交易日收盘价相对差异 ≤ 0.2%。

### 分红表

- `ex_date` 与 `cash_dividend_per_share` 不为空；
- 每股分红 ∈ [0, 100]（大于 100 视为每 10 股单位未转换）；
- 状态字段包含"实施"；
- 除权日在行情范围内的标记为有效，范围外的标记为忽略。

### 估值表

- `pe_ttm`、`pb`、`dividend_yield` 非负；
- 分位数 ∈ [0, 1]；
- 缺失率超过 30% 的标的标记警告。

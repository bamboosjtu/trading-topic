# Lab 5：银行股组合回测

## 目标

等单标的结果可信后，再做组合。本 Lab 在 Lab 3（单标的两流水验证）与 Lab 4（多标的并排比较）之上，研究核心问题：

> 多只银行股组合定投，能否降低最大回撤和最长亏损时间，以及是否会牺牲年化收益？

不引入主动再平衡、择时或权重优化。组合规则保持极简，与个人投资者"每月等额买入并持有"的实际行为对齐。

## 组合规则

| 规则 | 说明 |
|---|---|
| 每月总金额平均分配 | 总投入 3,000 元/月，5 只标的各 600 元 |
| 各标的现金独立归属 | A 标的的剩余现金不能用于 B 标的买入 |
| 不足一手继续结转 | 单标的当月 600 元不足买 1 手时，现金结转至下月 |
| 各标的分红只回购自身 | 工行分红只买工行，不跨标的再投资 |
| 不主动卖出再平衡 | 持仓比例随市值自然漂移，不强制回到等权 |
| 闲置资金获得历史逆回购收益 | 每个标的的剩余现金独立按 204001 计息 |
| 费用模型 | 简化费用（与 Lab 4 一致） |

### 与单标的回测的差异

组合回测不是"5 个单标的回测结果相加"，而是一套独立的账户体系：

- 每个标的有独立的现金子账户、持股子账户和分红子账户；
- 月度投入按等额分配到各子账户；
- 期末组合资产 = Σ 各子账户市值 + Σ 各子账户现金；
- 组合 XIRR 仅含外部总投入和期末总资产。

## 标的池

与 Lab 4 一致：工商银行、建设银行、农业银行、中国银行、招商银行。

可按相同流程扩展标的，但本 Lab 以这 5 只为基准组合。

## 回测口径

| 参数 | 取值 |
|---|---|
| 截止日 | 2026-07-24 |
| 周期 | 10 年、5 年、3 年 |
| 每月总投入 | 3,000 元 |
| 单标的月度分配 | 600 元（等额） |
| 买入日 | 每月 1 日，非交易日顺延 |
| 最小单位 | 100 股整数倍（每标的独立） |
| 分红处理 | 除权日收盘立即再投资原标的 |
| 剩余现金 | 各子账户独立按 204001 计息 |
| 费用模型 | 简化费用 |
| 再平衡 | 不主动再平衡 |

## 指标

### 组合层指标

| 指标 | 说明 |
|---|---|
| 累计投入 | 外部总投入之和 |
| 最终资产 | Σ 各子账户市值 + Σ 各子账户现金 |
| 累计收益率 | `最终资产 / 累计投入 - 1` |
| 年化收益率 XIRR | 仅含外部总投入和期末总资产 |
| 组合最大回撤 | 现金流调整后组合净值回撤 |
| 组合最大本金浮亏 | 组合资产相对累计总投入的最低浮亏 |
| 组合最长亏损时间 | 组合资产低于累计总投入的最长连续天数 |
| 组合波动率 | 组合日收益率 252 日年化波动率 |

### 子账户层指标

每个标的单独展示：

| 指标 | 说明 |
|---|---|
| 子账户累计投入 | 分配到该标的的总投入 |
| 子账户期末市值 | 该标的期末持股 × 收盘价 |
| 子账户期末现金 | 该标的剩余现金（含逆回购利息） |
| 子账户累计分红 | 该标的税后分红总额 |
| 子账户持股数量 | 该标的期末累计持股 |
| 子账户资金利用率 | 该标的累计买入金额 / 子账户累计投入 |

### 与单标的对比指标

本 Lab 的核心输出是组合与单标的的对比：

| 对比项 | 计算方式 |
|---|---|
| 收益 sacrifice | `组合 XIRR - max(单标的 XIRR)`，负值表示组合牺牲了收益 |
| 回撤 reduction | `组合最大回撤 - min(单标的最大回撤)`，负值表示组合降低了回撤 |
| 亏损时间 reduction | `组合最长亏损时间 - min(单标的最长亏损时间)`，负值表示组合缩短了亏损时间 |
| 风险调整收益 | `组合 XIRR / 组合波动率` vs 单标的的夏普比率代理 |

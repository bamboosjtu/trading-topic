# Task 4：银行股滚动回测

## 目标

固定起点只能回答"这一段历史怎样"，无法判断结论对起点是否敏感。本任务通过滚动窗口方法评估定投策略的稳定性，并对每只银行计算多个胜率指标，回答"任意起点开始定投 N 年，胜率有多大"。

## 滚动窗口

独立定义以下滚动窗口方法：

- 期限：3 年、5 年、10 年；
- 每个窗口连续投入 `期限 × 12` 期，在自己的结束月估值；
- 步长：1 个月（每个自然月作为新窗口的起点）；
- 对每只银行计算：XIRR 为正的比例、跑赢逆回购的比例、跑赢沪深300全收益的比例、跑赢中证500全收益的比例；
- 少于 12 个可比起点的窗口胜率显示 `N/A`，避免把 2 个高度重叠的窗口包装成稳定概率。

## 对比基准

并与以下标的进行对比：

- 国债逆回购 GC001 代理（`build_repo_level`）：与定投剩余现金计息口径一致；
- 沪深300全收益 `H00300`：代表大盘蓝筹；
- 中证500全收益 `H00905`：代表中盘成长。

基准标的同样使用滚动窗口等额定投口径，便于与银行股定投直接对比。

## 回测口径

| 参数 | 取值 |
|---|---|
| 截止日 | 2026-07-31 |
| 期限 | 3 年、5 年、10 年 |
| 每月投入 | **5,000 元/标的** |
| 买入日 | 每月 1 日，非交易日顺延 |
| 最小单位 | 100 股整数倍 |
| 分红处理 | 除权日收盘立即再投资原标的 |
| 剩余现金 | 按 204001 定盘利率逐日计息 |
| 费用模型 | 不计算手续费和分红税 |
| 卖出 | 不主动卖出 |

各标的资金独立结转，不跨标的调配。

## 数据来源

银行股数据来自 Task 1 标准表：

- `security_info.csv`：标的池筛选；
- `prices/<symbol>_daily_raw.parquet`：不复权收盘价；
- `dividends/<symbol>_dividend.parquet`：分红事件；
- `repo_rates.csv`：逆回购计息与基准；
- `trading_calendar.csv`：买入日顺延。

基准指数 H00300、H00905 的全收益日线需 Task 1 标准表的 `index_prices/<index_code>_daily.parquet` 提供。若 Task 1 未生成指数行情，则本任务需要补齐：使用 AKShare `stock_zh_index_daily_em` 或 `index_zh_a_hist` 获取指数全收益日线，按 Task 1 行情表 schema 落盘后供本任务读取。

## 验收标准

- [ ] 每只通过质量门禁的银行均生成 3 档期限 × 4 项胜率指标的滚动窗口结果表；
- [ ] 每个胜率指标记录窗口数、可比起点数、胜率，少于 12 个可比起点的标记 `N/A`；
- [ ] 基准 H00300、H00905、逆回购同样按滚动窗口等额定投口径计算胜率；
- [ ] 4 张图表全部生成，固定样本为 5 只代表性银行；
- [ ] 滚动窗口步长为 1 个月，不抽样或跳跃；
- [ ] 本任务不再调用任何上游 AKShare 接口（基准指数行情若 Task 1 已生成）。

历史回测只用于研究方法验证，不构成收益承诺。

# Task 3：多家银行并排比较

## 目标


1. 同样每月定投 5,000 元，不同银行的长期收益与风险差距有多大？
2. 哪些指标能稳定区分银行之间的差异，哪些指标受起点影响过大？

## 标的池

A股全部银行股，注意不同行业分类中标的的区别。从 Task 1 标准表的 `security_info.csv` 中筛选 `f10_is_bank=True` 或 `manual_verified=True` 的全部银行。

为图表清晰起见，固定样本图选用以下 5 只代表性银行：工商银行 601398、建设银行 601939、招商银行 600036、农业银行 601288、兴业银行 601166。表格展示全部通过质量门禁的银行。

## 回测口径

| 参数 | 取值 |
|---|---|
| 截止日 | 2026-07-31 |
| 周期 | 10 年、5 年、3 年 |
| 每月投入 | **5,000 元/标的** |
| 买入日 | 每月 1 日，非交易日顺延 |
| 最小单位 | 100 股整数倍 |
| 分红处理 | 除权日收盘立即再投资原标的 |
| 剩余现金 | 按 204001 定盘利率逐日计息 |
| 费用模型 | 不计算手续费和分红税 |
| 卖出 | 不主动卖出 |

各标的资金独立结转，不跨标的调配。

## 核心比较指标


### 1. 年化收益率（XIRR）

仅含外部投入和期末资产，内部分红与利息不计入外部现金流。上市晚于窗口起点的标的，该周期 XIRR 标记为 `N/A` 但保留实际参与月份。

### 2. 最大回撤

区分两类，均需展示：

- `strategy_max_drawdown`：现金流调整后策略净值回撤，回答"定投账户从高点跌了多少"；
- `max_loss_vs_contribution`：账户资产相对累计投入的最低浮亏，回答"最差时比本金亏多少"。

### 3. 最长亏损时间

`max_loss_duration_days`：账户资产低于累计投入的最长连续天数（Task 2 已实现）。该指标比最大回撤更能反映"定投心理压力持续时间"。

### 4. 分红稳定性

| 子指标 | 计算方式 |
|---|---|
| 连续派息年数 | 截至 2026-07-31，连续每年派息的年数 |
| 每股分红年化波动率 | 近 10 年每股派息的年化标准差 |
| 分红增长率 | 近 5 年每股派息的复合增长率 |

三项子指标综合判断分红稳定性，不单看一项。

### 5. 估值水平


| 子指标 | 说明 |
|---|---|
| 期末 PE_TTM | 2026-07-31 滚动市盈率 |
| 期末 PB | 2026-07-31 市净率 |
| 期末股息率 | 2026-07-31 近 12 个月股息率 |
| PE 5 年分位 | 当前 PE 在近 5 年的分位数（0-1） |
| PB 5 年分位 | 当前 PB 在近 5 年的分位数（0-1） |

估值水平不直接判断"高估"或"低估"，只提供分位数参考。

## 展示指标

除 5 项核心指标外，同时展示以下 7 项辅助指标，便于横向对照：

| 指标 | 说明 |
|---|---|
| 累计投入 | 外部现金流之和 |
| 最终金额 | 期末市值 + 期末现金 |
| 最终持股数量 | 期末累计持股（含送转股） |
| 累计分红 | 税前分红总额（未扣分红税） |
| 逆回购收益 | 剩余现金按 204001 计息的累计利息 |
| 期末闲置现金 | 期末未买入股票的现金余额 |
| 资金利用率 | `累计买入金额 / 累计投入` |

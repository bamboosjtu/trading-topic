# Task 1：银行股标准数据集

## 目标

将各数据接口返回值整理为统一的研究数据集，确保数据获取与数据使用解耦。Task 2～Task 4 只读取本任务生成的标准表，不再调用任何上游接口。

## 标准表清单

至少形成以下 8 张标准表：

### 1. 证券基本信息

| 字段                  | 类型 | 说明                              |
| --------------------- | ---- | --------------------------------- |
| `symbol`              | str  | 6 位证券代码，前补零              |
| `name`                | str  | 证券简称                          |
| `exchange`            | str  | SSE / SZSE / BSE                  |
| `list_date`           | date | 上市日期                          |
| `exchange_industry`   | str  | 交易所行业分类                    |
| `security_type`       | str  | 固定 `A-share`                    |
| `f10_is_bank`         | bool | mootdx F10 主营文本是否确认为银行 |
| `f10_matches`         | str  | 命中的银行关键词，`|` 分隔        |
| `manual_verified`     | bool | 是否在人工核验清单中              |
| `manual_review_as_of` | date | 人工核验清单截止日                |

### 2. 交易日历

| 字段       | 类型 | 说明             |
| ---------- | ---- | ---------------- |
| `date`     | date | 交易日           |
| `exchange` | str  | SSE / SZSE / BSE |
| `is_open`  | bool | 当日是否开市     |

用于 `contribution_dates` 的非交易日顺延判断。

### 3. 每日不复权行情

| 字段         | 类型  | 说明                                     |
| ------------ | ----- | ---------------------------------------- |
| `date`       | date  | 交易日                                   |
| `symbol`     | str   | 6 位代码                                 |
| `open`       | float | 开盘价                                   |
| `high`       | float | 最高价                                   |
| `low`        | float | 最低价                                   |
| `close`      | float | 收盘价（不复权）                         |
| `volume`     | float | 成交量                                   |
| `amount`     | float | 成交额                                   |
| `adjustment` | str   | 固定 `raw`                               |
| `source`     | str   | `AKShare-腾讯财经` 或 `AKShare-新浪财经` |

每支股票一个文件。

### 4. 现金分红事件

| 字段                      | 类型  | 说明                           |
| ------------------------- | ----- | ------------------------------ |
| `symbol`                  | str   | 6 位代码                       |
| `announcement_date`       | date  | 公告日期                       |

| `cash_per_10`             | float | 每 10 股派息金额（元）         |
| `cash_dividend_per_share` | float | 每股派息金额（元）             |
| `status`                  | str   | 方案进度，仅保留含"实施"的记录 |
| `source`                  | str   | `新浪财经` 或 `东方财富`       |

每只股票一个文件。

### 5. 送转股事件

| 字段                | 类型  | 说明                                           |
| ------------------- | ----- | ---------------------------------------------- |
| `symbol`            | str   | 6 位代码                                       |
| `ex_date`           | date  | 除权除息日                                     |
| `bonus_share_ratio` | float | 每股送股或转增比例（如 0.1 = 每 10 股送 1 股） |
| `source`            | str   | 数据来源                                       |

### 6. 每日估值

| 字段               | 类型  | 说明                  |
| ------------------ | ----- | --------------------- |
| `date`             | date  | 交易日                |
| `symbol`           | str   | 6 位代码              |
| `pe_ttm`           | float | 滚动市盈率            |
| `pb`               | float | 市净率                |
| `dividend_yield`   | float | 股息率（%）           |
| `pe_percentile_5y` | float | 5 年 PE 分位数（0-1） |
| `pb_percentile_5y` | float | 5 年 PB 分位数（0-1） |
| `source`           | str   | 数据来源              |

### 7. 国债逆回购收益率

| 字段       | 类型  | 说明                                 |

### 8. 数据来源与获取时间

记录本轮数据集的获取参数、路由选择、数量统计和已知局限。

| 字段                 | 说明                               |
| -------------------- | ---------------------------------- |
| `lab2_snapshot_date` | 本轮快照生成日期                   |

| `schema_version`     | 标准表 schema 版本号，便于向后兼容 |

> 历史字段名 `lab2_snapshot_date` 沿用，不改为 `lab01_*`，避免破坏旧 `run_manifest.json` 的兼容性判断。

## 数据源与路由

| 数据类型   | 主源                                 | 备源                        | 禁用                   |
| ---------- | ------------------------------------ | --------------------------- | ---------------------- |
| 不复权行情 | 腾讯 `stock_zh_a_hist_tx`            | 新浪 `stock_zh_a_daily`     | 东财 `stock_zh_a_hist` |
| 前复权行情 | 腾讯 `stock_zh_a_hist_tx`            | 新浪 `stock_zh_a_daily`     | 同上                   |
| 现金分红   | 新浪 `stock_history_dividend_detail` | 东财 `stock_fhps_detail_em` | —                      |
| 交易日历   | 交易所官方清单                       | —                           | —                      |
| 估值       | akshare 估值接口（待验证）           | —                           | —                      |
| 逆回购     | 上交所 204001 定盘利率               | —                           | —                      |

双源行情相对差异超过 0.2% 时阻断该股（沿用本 Lab 阈值）。

> AKShare `stock_zh_a_hist_tx` 仅支持不复权与前复权，**不支持后复权**。本数据集不产出后复权行情。

## 质量门禁

每张标准表落盘前必须通过以下检查，不合格的记录保留但标记，不静默丢弃：

### 行情表

- 日期升序、无重复、无空收盘价；
- OHLC 全部为正数，`low ≤ high`；
- 成交量非负；
- 最大日历间隔超过 20 天时标记警告（停牌或数据缺失）；
- 双源共同交易日收盘价相对差异 ≤ 0.2%。

### 分红表

- `ex_date` 与 `cash_dividend_per_share` 不为空；
- 每股分红 ∈ [0, 100]（大于 100 视为每 10 股单位未转换）；
- 状态字段包含"实施"；
- 除权日在行情范围内的标记为有效，范围外的标记为忽略。

### 估值表

- `pe_ttm`、`pb`、`dividend_yield` 非负；
- 分位数 ∈ [0, 1]；
- 缺失率超过 30% 的标的标记警告。

  `labs/data/lab2/audit/<snapshot-date>/`；
- `schema_version` 用于字段变更时的向后兼容判断。

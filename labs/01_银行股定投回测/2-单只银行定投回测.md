# Task 2：单只银行定投回测

## 目标

先用一只银行股把定投回测的每一笔交易讲清楚，验证交易流水完全符合直觉后，再计算复杂指标。本任务是 Task 3 多家银行比较的"纵深版"：聚焦单只股票，把交易细节、费用口径和现金结转逐笔审计。

选择工商银行（601398）作为样本：上市最早、分红记录最长、流动性最高，便于覆盖 10 年窗口。

## 回测口径

### 基础规则

| 参数 | 取值 | 说明 |
|---|---|---|
| 标的 | 工商银行 601398 | SSE 主板 |
| 周期 | 10 年、5 年、3 年 | 三档对比 |
| 每月投入 | **5,000 元** | 固定金额 |
| 买入日 | 每月 1 日 | 非交易日顺延至下一个交易日 |
| 最小单位 | 100 股（1 手） | 严格按一手整数倍买入，剩余资金留现金 |
| 分红处理 | 税前每股派息，除权日收盘立即再投资原标的 | 不分配到现金账户 |
| 送转股 | 按每股比例增加份额 | 不视为卖出 |
| 卖出 | 不主动卖出 | 仅在期末估值时计算市值 |
| 剩余现金 | 按历史逆回购收益计息 | 见下文 |

### 剩余现金逆回购计息

计息规则：

- 每个交易日按前一日 204001 定盘利率 × 实际日历天数 / 365 计息；
- 利息计入现金账户，下次买入时可使用；
- 不计手续费与成交偏差；该口径由本任务独立定义并通过确定性样例校验。

### 费用模型

**不计算手续费和分红税**。分红按税前每股派息全额计入现金账户后立即再投资。流水表 `fee`、`dividend_tax` 字段保留但固定为 0，便于未来扩展费用模型时对照。

## 交易流水验证

在计算任何收益指标之前，必须先验证每一笔交易符合直觉。对每个周期生成完整交易流水表，逐笔核对以下 7 项：

| 验证项 | 检查内容 | 预期 |
|---|---|---|
| 当月投入 | 月度投入金额是否到账 | **5,000 元/月**，首月交易日到账 |
| 买入手数 | 按收盘价能买多少手 | `floor(cash / (close × 100)) × 100`，至少 1 手或 0 手 |
| 剩余现金 | 买入后现金余额 | `cash - buy_shares × close`，非负 |
| 登记日持股 | 股权登记日持股数量 | 取登记日之前最近一次持仓快照 |
| 分红金额 | 收到的现金分红 | `登记日持股 × 每股派息`（税前） |
| 再买入手数 | 分红再投资买入的手数 | 按除权日收盘价计算，可能为 0 手（分红不足买 1 手） |
| 期末持股 | 期末累计持股 | 等于所有买入手数之和（送转股另计） |

### 流水表 schema

`data/transactions/<symbol>_<horizon>_<fee_model>.csv`，`fee_model` 固定取值 `no_fee`：

| 字段 | 说明 |
|---|---|
| `date` | 交易日 |
| `trade_type` | `monthly_contribution` / `dividend_reinvest` / `repo_interest` |
| `buy_price` | 买入价（收盘价） |
| `buy_shares` | 买入股数（100 的整数倍） |
| `buy_amount` | 买入金额（不含费用） |
| `fee` | 本次交易费用（当前固定 0） |
| `remaining_cash` | 交易后现金余额 |
| `cumulative_shares` | 累计持股 |
| `cumulative_contribution` | 累计外部投入 |
| `repo_interest_accrued` | 当日逆回购利息 |
| `dividend_received` | 当日分红入账（税前全额） |
| `dividend_tax` | 当日分红税（当前固定 0） |

## 指标

交易流水验证通过后，计算以下指标。三档周期 × 单一费用模型 `no_fee` = 3 组结果。

### 收益指标

| 指标 | 计算依据 |
|---|---|
| 累计投入 | 外部现金流之和 |
| 最终资产 | 期末市值 + 期末现金（含逆回购利息） |
| 累计收益率 | `最终资产 / 累计投入 - 1` |
| 年化收益率 XIRR | 仅含外部投入和期末资产，内部分红与利息不计入外部现金流 |
| 平均买入价 | 累计买入金额 / 累计买入股数 |
| 当前持仓收益率 | 期末收盘价 / 平均买入价 - 1 |

### 风险指标

三类风险指标语义分离，不混用（与本 Lab 一致）：

| 指标 | 含义 |
|---|---|
| `max_drawdown` | 标的含分红总回报净值最大回撤 |
| `max_loss_vs_contribution` | 账户资产相对累计投入的历史最低浮亏 |
| `strategy_max_drawdown` | 现金流调整后策略净值回撤（先剔除新增本金） |
| `volatility` | 标的总回报日收益率 252 日年化波动率 |
| `max_loss_duration_days` | 账户资产低于累计投入的最长连续天数 |

`max_loss_duration_days` 对应"最长亏损时间"，需新增实现：遍历账户历史，找到 `account_asset < cumulative_contribution` 的最长连续区间。

### 分红与现金指标

| 指标 | 说明 |
|---|---|
| 累计分红 | 所有分红入账金额之和（**税前**，未扣分红税） |
| 累计逆回购收益 | 剩余现金按 204001 计息的累计利息 |
| 期末闲置现金 | 期末未买入股票的现金余额 |
| 资金利用率 | `累计买入金额 / 累计投入` |

## 图表

`/charts/<symbol>/` 保存以下图表，单一费用模型一组：

1. 资产构成堆叠图：按月展示市值 + 现金 + 累计投入三条线，验证投入与资产的关系；
2. 交易流水时间线：标注每月买入、分红入账、再投资买入的事件点；
3. 三档周期 XIRR 对比柱状图：验证不同投资期限对收益的影响幅度；
4. 账户浮亏区间图：标注 `account_asset < cumulative_contribution` 的时段，对应 `max_loss_duration_days`；
5. 现金余额与逆回购收益曲线：验证剩余现金计息逻辑。

## 验收标准

- 三档周期交易流水表全部生成；
- 每笔交易验证项全部通过人工抽查；
- `max_loss_duration_days` 正确计算，与图表标注的浮亏区间一致；
- 5 张图表全部生成，数字与流水表一致；
- 期末持股 = 所有买入手数之和 + 送转股增加份额；
- 流水表 `fee`、`dividend_tax` 字段固定为 0，分红按税前金额入账。

历史回测只用于研究方法验证，不构成收益承诺。

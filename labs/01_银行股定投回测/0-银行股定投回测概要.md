# 银行股月度定投与分红再投资回测

## 目标

形成可重复运行的银行股研究链路：

```text
股票池 → 行情 → 分红 → 回测 → 指标 → 图表
```

本 Lab 下设 4 个 Task，对应 1～4 号 Notebook：

| Task | 主题 | 输入 | 输出 |
| --- | --- | --- | --- |
| Task 1 | 银行股标准数据集 | 交易所清单、行情接口、分红接口 | 8 张标准表 + `run_manifest.json` |
| Task 2 | 单只银行定投回测 | Task 1 标准表（工商银行 601398） | 交易流水、9 组指标、5 张图 |
| Task 3 | 多家银行并排比较 | Task 1 标准表（全部银行股） | 横向对比指标表、6 张图 |
| Task 4 | 银行股滚动回测 | Task 1 标准表 + 沪深300/中证500/逆回购 | 滚动窗口胜率表、4 张图 |

## 数据与路由

- 股票池：沪、深、北交易所 A 股清单，从中挑选出所有的银行股。
- 不复权行情：腾讯 `stock_zh_a_hist_tx` 为主源，新浪 `stock_zh_a_daily` 为备源和质量校验源；
- 前复权行情：仅用于连续走势及后续技术研究，不进入现金流回测；
- 分红：新浪 `stock_history_dividend_detail` 为主源，东方财富 `stock_fhps_detail_em` 为备源，只使用已实施现金分红。

> AKShare `stock_zh_a_hist_tx` 仅支持不复权与前复权，**不支持后复权**。回测现金流一律使用不复权收盘价加每股现金分红构建标的总收益净值。

数据写入 `data/` 目录：

- `bank_universe.csv`：银行股票池；
- `prices/<symbol>_daily_raw.parquet`：不复权行情；
- `prices/<symbol>_daily_qfq.parquet`：前复权行情；
- `prices/<symbol>_daily_sina_raw.parquet`：新浪校验行情；
- `dividends/<symbol>_dividend.parquet`：统一为每股现金分红的数据；
- `results/backtest_results.csv`：每只股票、每个周期一行；

这些文件是可再生实验数据，默认不提交 Git。

## 回测口径

- 截止日：2026 年 7 月 31 日；
- 周期：10 年、5 年、3 年；
- 每月投入 **5,000 元**，不够一手，留着等下月；
- 不计算手续费和分红税；
- 股权登记日持股决定应收分红；
- 分红统一为每股金额，没有实际到账日时，以除权除息日近似入账并再投资；
- 上市晚于窗口起点或数据无法完整覆盖时，比较指标为 `N/A`，但保留实际参与月份；
- 双源共同交易日收盘价相对差异超过 0.2% 时，停止该股票全部周期的回测，并将告警记录在 `quality_report.csv` 中。

## 指标

收益指标包括累计收益率、XIRR、平均买入价和当前持仓收益率。XIRR 使用实际现金流日期，只把外部月度投入和期末资产计入现金流。

风险指标必须区分：

- `max_drawdown`：基于不复权价格与现金分红构建的标的总收益净值最大回撤；
- `max_loss_vs_contribution`：定投账户资产相对累计投入的历史最低浮亏；
- `strategy_max_drawdown`：现金流调整后策略净值回撤（剔除新增本金影响）；
- `max_loss_duration_days`：账户资产低于累计投入的最长连续天数；
- `volatility`：标的总收益日收益率的 252 日年化波动率。

## 图表

图表保存到 `charts/` 目录：

1. 三周期 XIRR 热力图；
2. 累计收益率分组柱状图；
3. 典型银行资产曲线；
4. 风险收益散点图；
5. 分红贡献图。

图表只纳入满足完整窗口且通过质量门禁的结果，不把所有银行股价格线叠加在一张图上。

## 验收标准

- 每只股票有不复权、前复权和新浪校验行情快照；
- 每只股票有标准分红快照和质量检查记录；
- 不完整窗口和数据质量阻断的指标明确为 `N/A`，不得静默跳过；
- 两类风险指标语义分离，年化收益率使用 XIRR；
- 五张图、回测流水、账户历史、标的总收益历史及运行清单均能生成；
- Notebook 无错误输出。

历史回测只用于研究方法验证，不构成收益承诺。

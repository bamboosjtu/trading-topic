## 设置页可观测性改动

| 改动 | 行为 | 边界 |
| --- | --- | --- |
| 新增“数据源实时可用性”区块 | 用户显式点击后检查七项产品来源，逐项显示实际来源、固定路由、状态、延迟、截止日、详情和失败原因 | 不在打开设置页时自动发起全量请求，避免无意义消耗和限流 |
| 新增结构化健康契约与 IPC | `DataSourceHealthReport` 从 Main 经 Preload 暴露到 Renderer；七项失败互相隔离，单项异常不会让其他结果消失 | 结果不持久化，不进入投资事实、行情缓存或目录快照 |
| 保留固定路由 | 腾讯主源 / 新浪备用、ETF 新浪单源、停复牌东财主源 / 百度备用均由产品契约控制 | 不提供绕过解析、跨源一致性或完整性门禁的用户开关 |
| 来源级节流 | 东方财富公司行动与停复牌探测串行间隔，东财停复牌分页至少间隔 1,200ms；百度按 31 天分段 | 健康检查本身不放大上游限流风险 |
| 停复牌入口重新定位 | 页面明确自动同步是主流程，“添加停牌证据”改为“添加人工补充证据” | 人工证据继续保留，不能被自动源替换或删除 |
| 数据库不变 | 新能力不新增表、列或设置项 | `PRAGMA user_version` 与 Schema 指纹均不因本功能变化 |

健康检查的 `available` 代表本次请求成功且通过最小语义门槛；`degraded` 代表备用源成功或返回了可降级问题；`unavailable` 代表传输、协议、解析或稳定样本门槛失败。设置页会明确显示“结果只代表这一次请求”。

## 停复牌修复实现

### 根因

修复前产品把停复牌复用了面向个股历史的通用东方财富报表请求：`reportName=RPT_SUSPENDDATA`、`filter=(SECURITY_CODE="...")`。东方财富已删除或停用该报表配置，所以服务层虽然仍会在回测和持仓刷新前自动调用，但每个标的都会失败、记录 warn 并保留旧证据，首次使用或没有旧证据时只能按“无自动停牌证据”继续。

AKShare `1.18.82` 的有效实现改用 `reportName=RPT_CUSTOM_SUSPEND_DATA_INTERFACE`、`filter=(MARKET="全部")(DATETIME='YYYY-MM-DD')`、`pageSize=500` 和全分页。新报表是市场级日期查询，不是旧接口的个股历史查询；参数和覆盖语义已经变化，不能只替换 `reportName`。

### 已完成实现

1. **专用主源适配器。** `RPT_CUSTOM_SUSPEND_DATA_INTERFACE` 使用市场级范围起点、每页 500 行、严格全分页、分页总数稳定性、命名字段校验、证券过滤、去重和范围交集过滤，不再复用旧个股报表函数。
2. **独立备用源。** 百度 `financecalendar` 使用 `cate=notify_suspend`、最多 31 天一段、每页 100 行、逐日覆盖与逐日总数校验；复牌日换算为最后停牌日，同日盘中临停和没有复牌日的开放记录不伪装成整日闭合区间。
3. **批量刷新。** 回测按请求区间、持仓按 13 个月刷新窗口一次查询全部 symbols，不再逐标的重复请求市场级接口。
4. **范围原子替换。** 新数据库仓储操作只删除与已确认覆盖范围相交的声明自动来源；主源恢复时清理同范围旧百度证据，备用成功时保留旧东财历史，人工来源和范围外记录始终不受影响。
5. **失败保留。** HTTP 错误、错误码、缺页、总数变化、日期覆盖不完整、字段漂移和非空零解析均不会进入替换事务；主备均失败时保留全部旧证据并写 warn。
6. **覆盖边界。** 百度可验证结构化历史从 2023-01-01 起，早期请求会显式返回部分覆盖；该边界进入同步日志和设置页健康说明，不把未查询历史解释成“无停牌”。

### 验收结果

- 固定样本 `603221` 的主源与备用源均得到停牌开始日 2026-08-03、最后停牌日 2026-08-05，真实联网检查均为 `available`。
- 受控东财 HTTP 503 后自动路由返回百度证据、`fallbackUsed=true` 和明确 `fallbackReason`，证明备用不是只存在于文档。
- contract 测试覆盖主源开放区间、字段漂移、百度复牌日换算、未闭合区间、日期覆盖、部分历史和受控主源故障切换；integration 测试覆盖范围替换、主源恢复清理旧备用、人工证据与范围外历史保留。
- 修复不依赖 Labs / AKShare 运行时，不提升数据库 Schema 版本，不改变行情、分红、手续费或回测收益口径。

## 剩余风险

1. **百度备用在 2023-01-01 之前是部分覆盖。** 早期回测遇到东财主源故障时不会静默清空旧证据，但可能仍因缺少停牌证据而报告行情缺口；人工公告补证入口继续保留。
2. **百度未闭合历史记录不能证明最终复牌日。** 备用适配器会跳过此类记录并报告数量；东财当前动态报表可以把仍开放事件保存到本次已观察截止日，但不宣称最终结束日。
3. **ETF 现在是新浪单源。** 这是用户指定路由，消除了当前不可用的东财前置请求，但也意味着新浪目录失败时只能使用七天内旧完整快照或报错。
4. **公司行动仍是东方财富单点。** Lab00 的同花顺与巨潮接口当次可用只证明存在候选证据源，不代表字段和实施语义已对齐。
5. **腾讯、新浪、东方财富和百度均为未版本化网页后端。** 结构校验能阻止部分静默错误，不能承诺持续可用；设置页状态和发布 smoke 都只代表当次请求。
6. **交易日历长历史不完整。** 2024—2026 为 official，15 年回测中的 2011—2023 会明确标记为 `research`；2027 仍为 `pending_official_schedule`。
7. **Renderer 产物偏大。** 本次构建中 Backtest 页面 chunk 约 2.59 MB，另有约 1 MB 级 chunk；不影响正确性，但后续可继续按 Excel / ECharts 边界延迟加载。
